# Contributing

Build on Windows with `Source/Build.ps1`. Keep equipment guidance tied to the selected model and its cited specifications, and retain the notes and licenses for bundled data. Avoid committing local settings, observing coordinates, downloaded images or generated compiler/build files.

For application changes, run the checks relevant to the affected calculations and controls. Existing test entry points are in `Source/NightLens.cs`; some need weather/seeing fixtures that are not included in this source archive. Record the fixtures and observing date used when reporting results.

Capture guidance is heuristic. Missing forecast data must remain explicit, and weather must not remove full-night planning targets.
